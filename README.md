# Пока жду

Мобильный веб-сайт (PWA) для краудсорсинговой разметки коротких видеоклипов.
Человек сканирует QR-код на остановке и, пока ждёт автобус, отвечает на вопрос
«Человек в рамке курит?» для 3–5 клипов. Ответы нужны для обучения модели,
которая распознаёт курение (сигареты и вейпы) на уличных камерах.

* **Фронтенд** — React 18 + Vite + TypeScript, PWA (manifest, service worker), ≈ 62 КБ JS gzip.
* **Бэкенд** — Python 3.12, FastAPI, PostgreSQL, S3-совместимое хранилище (локально — SeaweedFS S3).
* **Архитектура, схема БД, алгоритмы качества** — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт (Docker Compose)

```bash
cp .env.example .env          # для локального запуска можно не менять
docker compose up --build
```

| Что | Адрес |
|---|---|
| Приложение (остановка «Парк Победы») | http://localhost:8080/?stop=1284 |
| Админка (токен — `ADMIN_TOKEN` из `.env`) | http://localhost:8080/admin |
| Swagger API | http://localhost:8080/api/docs |
| S3-хранилище клипов (ключи — `deploy/seaweedfs-s3.json`) | http://localhost:9000 |

Сервис `seed` один раз создаёт схему, 5 демо-остановок, 30 демо-клипов (6 золотых)
и ответы 40 имитированных разметчиков, чтобы в админке были статистика, kappa и экспорт.
Повторный запуск не дублирует данные.

> Для проверки на телефоне в той же сети откройте `http://<IP-компьютера>:8080/?stop=1284`
> и задайте в `.env` `S3_PUBLIC_ENDPOINT=http://<IP-компьютера>:9000` — по этому адресу
> браузер скачивает клипы. Service worker и установка PWA требуют HTTPS (кроме `localhost`).

## Локальная разработка без Docker

Нужны Python 3.12+, Node 20+, PostgreSQL 14+ и ffmpeg (только для перегенерации демо-клипов).

```bash
# БД
createuser -P pz          # пароль pz
createdb -O pz pokazhdu

# бэкенд
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python -m app.cli seed --demo-answers     # клипы копируются в ./media (STORAGE_BACKEND=local)
uvicorn app.main:app --reload --port 8000

# фронтенд (в другом терминале)
cd frontend
npm install
npm run dev               # http://localhost:5173/?stop=1284, /api проксируется на :8000
```

### Тесты

```bash
createdb -O pz pokazhdu_test
cd backend && pytest       # TEST_DATABASE_URL, по умолчанию postgresql://pz:pz@localhost:5432/pokazhdu_test
cd frontend && npm run typecheck
```

Тесты API пересоздают схему в **отдельной** тестовой БД и проверяют выдачу клипов,
3 голоса на клип, золотые клипы, антиспам (слишком быстро, «пулемёт», одинаковые ответы
подряд, лимиты), жалобы, отзыв согласия и удаление данных, табло, админку и экспорт.

## Как устроено

### Сценарий пользователя

1. QR-код ведёт на `https://…/?stop=<id>`. Без регистрации: при согласии сервер выдаёт
   случайный анонимный ID и подписанный токен, они хранятся в `localStorage`.
2. Онбординг из двух экранов: зачем это нужно (+ чекбокс согласия) и пример разметки.
   Вернувшийся пользователь сразу попадает к клипу.
3. Клип 3–5 с, без звука, по кругу, кнопка «Повторить», рамка вокруг человека
   (трек координат с бэкенда, интерполяция по времени). Ответ: 4 крупные кнопки
   или свайпы (переключение в памятке «?»). Для «Не курит» — необязательное
   уточнение, которое само закрывается через 6 с.
4. На золотых клипах — «Совпало с экспертом ✓» / «Эксперт ответил иначе» с пояснением.
5. Итог сессии: вклад, «вместе мы разметили», уровень с прогрессом, серия дней,
   вклад остановки и табло, «Ещё 3 клипа» / «Мой автобус пришёл».

### Качество данных

* Каждый клип размечают ≥ 3 разных человека; итоговая метка — взвешенное большинство,
  вес = сглаженная точность на золотых клипах. При уверенности < 0.7 клип
  выдаётся ещё (до 7 голосов).
* Золотые клипы ≈ 12% выдачи (`GOLD_RATE`); новичку — один сразу.
  При очень низкой точности пользователь получает только проверочные клипы,
  его ответы не попадают в датасет.
* Приоритет выдачи: клипы с малым числом голосов → с расхождением → из того же района.
* Антиспам: ответ быстрее 1 с, ответы чаще 300 мс, 12 одинаковых подряд — отбрасываются
  (сохраняются для аудита); лимиты в день на устройство и IP и за 30 минут; rate limit.
* Для каждого ответа хранятся `clip_id, user_id, answer, sub_answer, response_time_ms,
  stop_id, created_at`.

### Приватность и безопасность

* Клипы приходят уже размытыми (лица, номера) из пайплайна, без звука, адреса и времени.
* Никаких персональных данных: случайный UUID; вместо IP — `HMAC(день + IP)`.
* «О проекте»: цель, использование данных, контакт, согласие (можно отозвать) и удаление ответов.
* Жалоба на клип сразу убирает его из выдачи пожаловавшегося; «видно лицо/номер» и
  «неприемлемо» скрывают клип для всех до решения модератора (вкладка «Жалобы» в админке).
* CSP, `nosniff`, `no-referrer`, запрет фреймов; токен в заголовке (без cookies → нет CSRF);
  подписанные URL клипов на 10 минут; rate limiting в nginx и в приложении.

### Админка и экспорт

`/admin`: сводка по классам и состояниям разметки, отброшенные ответы, Cohen's kappa
(попарно и с итоговой меткой), Fleiss' kappa, точность разметчиков на золотых, жалобы,
экспорт JSON/CSV (`clip_id, final_label, votes, confidence, label_state, is_gold,
score_*, top_no_reason, duration_ms, bbox`). То же через API:

```bash
curl -H "Authorization: Bearer $ADMIN_TOKEN" "http://localhost:8080/api/admin/export?format=csv&state=done" -o labels.csv
```

### Загрузка своих клипов

Клипы должны быть подготовлены пайплайном: 3–5 с, без звука, H.264 ≤ 720p, ≤ 1 МБ,
`-movflags +faststart`, лица и номера размыты. Опишите их в `manifest.json`
(формат — как в [backend/seed/manifest.json](backend/seed/manifest.json)):

```json
{
  "stops": [{ "id": "1284", "name": "Парк Победы", "region": "central" }],
  "clips": [{
    "external_id": "cam12_20240101_0001", "file": "clips/0001.mp4",
    "duration_ms": 4000, "width": 1280, "height": 720, "region": "central",
    "bbox": [{ "t": 0, "x": 0.31, "y": 0.18, "w": 0.12, "h": 0.6 }, { "t": 4, "x": 0.35, "y": 0.18, "w": 0.12, "h": 0.6 }],
    "gold": { "answer": "cig", "explanation": { "ru": "Видна сигарета у рта и дым." } }
  }]
}
```

```bash
docker compose run --rm seed python -m app.cli import-clips /path/in/container/manifest.json
```

`bbox` — ключевые кадры рамки в долях кадра; поле `gold` — только для золотых клипов.
Демо-клипы синтетические, их генератор — `backend/seed/generate_clips.py`.

### Локализация

Строки — в `frontend/src/i18n/ru.ts` (по умолчанию) и `en.ts` (пример, включается `?lang=en`).
Чтобы добавить язык, создайте `<код>.ts` по образцу `en.ts` и подключите его в
`frontend/src/i18n/index.ts`; пояснения к золотым клипам задаются по языкам в `explanation`.

### Основные параметры (`.env`)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `SECRET_KEY` | — | подпись токенов, URL и хэш IP — **обязательно поменять** |
| `ADMIN_TOKEN` | — | доступ к админке |
| `REQUIRED_VOTES` / `MAX_VOTES` / `CONSENSUS` | 3 / 7 / 0.7 | правила итоговой метки |
| `GOLD_RATE` | 0.12 | доля золотых клипов в выдаче |
| `MIN_RESPONSE_MS` | 1000 | ответы быстрее отбрасываются |
| `DEVICE_DAILY_LIMIT` / `SESSION_LIMIT` / `IP_DAILY_LIMIT` | 60 / 30 / 400 | лимиты ответов |
| `CLIP_URL_TTL` | 600 | срок жизни подписанного URL клипа, с |

Полный список — `backend/app/config.py`.
